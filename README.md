# openlakeforge.github.io

The public website of [OpenLakeForge](https://github.com/OpenLakeForge/openlakeforge):
a presentation page and the documentation, served at
**https://openlakeforge.github.io/**.

Built with Astro and Starlight in the OpenLakeForge **Deep Water** design
system. The documentation is synced at build time from the openlakeforge
repository at its latest release tag.

**Status:** planned. See [PLAN.md](PLAN.md) for the build plan.
