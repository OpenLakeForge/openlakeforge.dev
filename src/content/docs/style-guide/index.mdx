Bring up the full OpenLakeForge stack on a local kind cluster, run the sample
pipeline end to end, and open every service from the platform portal. You need
**Docker** and [uv](https://docs.astral.sh/uv/); `olf` provisions its own
pinned Terraform, Helm, kubectl and kind.

## Prerequisites

You need Docker, kind and uv. Everything else is pinned and fetched by `olf`
itself, so the versions always match the release.

1. Install the CLI with `uv tool install openlakeforge`.
2. Create a project with `olf init`.
3. Deploy with `olf deploy --provider local`.

- **Slim** (default): ingestion, validation, Iceberg, catalog, Trino, dbt and Dagster.
- **Full**: Slim plus OpenMetadata governance and Superset dashboards.

### Slim or Full?

| Preset | Includes | Use it when |
| --- | --- | --- |
| **Slim** | Ingestion, validation, Iceberg, catalog, Trino, dbt and Dagster | You want the shortest path to a working lakehouse |
| **Full** | Slim + OpenMetadata + Superset | You also want governance, lineage and dashboards |
