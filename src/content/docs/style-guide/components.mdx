## Callouts

The sync turns GitHub alerts (`> [!NOTE]`…) into these (PLAN.md, rule T6).

<Aside type="note">Authentication is off for local evaluation; every service signs you in as admin.</Aside>
<Aside type="tip">Run `olf e2e run --env local` after deploy to verify the whole stack.</Aside>
<Aside type="caution">Destroying the stack deletes every bucket in the local object store.</Aside>
<Aside type="danger">Never commit the GitHub App private key to `lakehouse_code/`.</Aside>

## Code

```bash title="Terminal"
uv tool install "openlakeforge==0.4.0a1" --python 3.12
olf init                      # writes openlakeforge.yaml and lakehouse_code/
olf deploy --provider local   # builds the kind cluster and the whole platform
```

```yaml title="openlakeforge.yaml"
apiVersion: openlakeforge.io/v1
kind: DeploymentProfile
spec:
  provider: local
  preset: slim        # or full
  stages: [dev, prod]
```

```python title="pipelines/dagster/definitions.py"
from dagster import Definitions, asset

@asset(group_name="sales")
def order_revenue(orders: list[dict]) -> float:
    """Gold mart: total revenue per day."""
    return sum(row["amount"] for row in orders)

defs = Definitions(assets=[order_revenue])
```

## Steps

<Steps>

1. Install the CLI: `uv tool install openlakeforge`.
2. Create a project: `olf init`.
3. Deploy: `olf deploy --provider local`, then open `http://olf.localhost`.

</Steps>
